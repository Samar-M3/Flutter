# Jaandristhi

## Short Description
**Jaandristhi** is a modern, responsive cross-platform mobile application built with Flutter. It features a polished authentication module with a stunning gradient UI, secure input fields, form validation, and seamless navigation between the **Login** and **Register** screens.

---

## Features
- **Modern Authentication Flow:** Smooth navigation between Login and Registration screens.
- **Sleek UI Design:** Beautiful purple-to-violet gradient background (`#5B5FEF` to `#8B5CF6`) with rounded card containers and clean typography (`Roboto`).
- **Interactive Form Fields:**
  - Full Name, Email Address, Password, and Confirm Password inputs.
  - Password visibility toggle (show/hide password functionality).
- **Material 3 Support:** Built using the latest Flutter Material 3 design guidelines and color schemes.
- **Cross-Platform:** Ready for Android, iOS, and Web deployment.

## How to Run the Project

### Prerequisites
- Ensure you have [Flutter SDK](https://docs.flutter.dev/get-started/install) installed on your machine.
- An emulator (Android/iOS) or a connected physical device, or Chrome for web.

### Steps to Run
1. **Clone the repository or open the project folder:**
   ```bash
   cd jaandristhi
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the app:**
   ```bash
   flutter run
   ```
